Avant la première requête

Le plus simple : partir du modèle Power BI

Le modèle Modele_API_Melodi.pbit contient déjà les 7 requêtes (fonctions Melodi v1.2 et v1.5, paramètres, référentiel des communes), avec leurs descriptions et un exemple. À l'ouverture, Power BI demande le millésime, les départements du périmètre et l'adresse de votre copie du référentiel.

Télécharger le modèle Power BI (.pbit)

Pour un rapport existant : coller les 7 requêtes

Les deux fonctions Melodi, le millésime du recensement, les départements du périmètre (67 et 68 par défaut), l'adresse du référentiel des communes, le référentiel lui-même et la liste des communes. Elles sont dans l'onglet « Fonctions » du générateur, à coller une fois par fichier, sans rien modifier.

Dans les deux cas, télécharger le référentiel des communes (.xlsx), le déposer sur SharePoint ou OneDrive et mettre son adresse dans le paramètre P_Chemin_Referentiel.

Ce qui part sur Internet

Rien au chargement de la page. Le bouton « Charger le dictionnaire ici » interroge l'API de l'Insee (api.insee.fr) ; l'onglet « Tester » ouvre une de ses adresses. Dans Power BI, les requêtes appellent api.insee.fr (sans compte ni clé) et lisent le référentiel à l'adresse de P_Chemin_Referentiel.

Écrit la requête Power Query qui charge un jeu Insee par l'API Melodi. Les guillemets, les listes { } et les virgules sont posés pour vous. Le code produit est celui des fonctions v1.5 : le filtre géographique est envoyé à l'API, sans téléchargement de la France entière ; un dépassement de la limite de 30 appels par minute déclenche une pause puis un nouvel essai ; une réponse vide déclenche une erreur explicite plutôt qu'une table vide.

Partir du modèle Power BI, qui contient déjà les 7 requêtes

Rien à coller : ouvrir Modele_API_Melodi.pbit, choisir le millésime, les départements et l'adresse de votre copie du référentiel, puis ajouter les requêtes écrites ici.

Télécharger le modèle Power BI (.pbit)

Ou, pour un rapport existant : coller les 7 requêtes de l'onglet « Fonctions »

Dans l'ordre, sans rien modifier : fn_MelodiDico, fn_MelodiData, P_Millesime_RP, P_Departements_Perimetre, P_Chemin_Referentiel, DIM_Referentiel_Geographique, puis P_Communes_Perimetre. Toutes les requêtes du générateur fonctionnent ensuite telles quelles.

1Le jeu de données

Le nom se lit sur la fiche du jeu dans le catalogue des données Insee.

Le format dépend du jeu : 2023 (année), 2025-03 (mois), 2025-03-15 (jour). Les codes existants se lisent dans le dictionnaire, variable TIME_PERIOD.

2Le dictionnaire : lire les codes

Avant d'écrire les filtres, charger le dictionnaire du jeu : il donne pour chaque variable (VARIABLE) la liste de ses codes (CODE) et leurs libellés.

3Les filtres

Une ligne par variable, avec les codes lus dans le dictionnaire. Plusieurs valeurs : les séparer par des virgules, la liste { } est faite automatiquement. Le millésime et le territoire se règlent à part.
